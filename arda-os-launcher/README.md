# ARDA OS Launcher v0.1

Lightweight Android HOME launcher prototype for NADMO / ARDA OS.

## Included
- Registers as Android HOME launcher
- Cyberdeck-inspired home screen
- Live clock/date
- Quick Settings shortcuts
- Functional app drawer from installed apps
- Direct app launching
- No root
- No background tracking/service

## Install
Install the generated debug APK, press Home, then choose **ARDA OS** as the default Home app.

To restore the stock launcher: Android Settings > Apps > Default apps > Home app.

Phone/camera package names vary by manufacturer. If a dock shortcut is unavailable it falls back to the app drawer.
