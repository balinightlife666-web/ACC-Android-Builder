# LOST & FOUND: NIGHT SHIFT — M1 VISUAL LOCK v1.0

Status: ACTIVE
Milestone: M1 — PREMIUM ROOM

## Visual language
Premium stylized Roblox airport back-office / Lost & Found operations room.

Core palette and material hierarchy:
- charcoal / graphite architecture
- brushed dark metal equipment
- warm amber task and service lighting
- cool cyan scanner / evidence technology accents
- restrained red quarantine / security accents
- muted green return / routine clearance accents

## Tone
- believable operational workplace first
- mysterious night-shift atmosphere second
- premium and readable, not oppressive
- no neon-arcade floor look
- no giant airport exterior
- no decorative clutter that blocks gameplay

## Room hierarchy
1. service counter / intake desk is the main workplace anchor
2. conveyor visually feeds the inspection station
3. scanner is the clearest technology hero prop
4. inspection desk is compact and readable
5. claimant waiting point is visually separate from staff work zone
6. decision area reads as an operational control station, not four glowing arcade pads
7. quarantine access is visibly restricted and ominous without horror gore

## Lighting
- overhead cool-white industrial fixtures for base visibility
- local amber task light at service/intake area
- cyan scanner glow used sparingly
- red quarantine light only near restricted access
- subtle contrast / bloom only; no blown-out neon

## Geometry rule
M1 may continue using procedural Roblox geometry for room architecture and equipment while premium external item meshes are curated separately.
Procedural architecture must use layered silhouettes, trims, frames, inset panels, rails, control surfaces, and material contrast so it no longer reads as simple boxes.

## Gameplay protection
Visual upgrades must not change the locked gameplay loop:
`SCAN → CHECK TAG → OPEN / INSPECT → DECIDE`

Maintain mobile-safe movement paths and clear interaction distances.
