# ARDA OS Desktop v0.3.2

Safe-mode Windows cyberdeck launcher.

## v0.3.2
- Fixes the Discord quick-module button.
- If Discord is already running in the tray/background, ARDA OS restores and focuses its window.
- Tries the standard LocalAppData Discord installer path, latest app-* Discord.exe, Start Menu shortcut, then discord: protocol and Discord Web.
- Keeps the v0.3.1 right-status layout, autostart repair, live telemetry, ACC CORE, quick modules, visual app drawer, and taskbar toggle.

## Shortcuts
- Ctrl+Space: Apps
- Ctrl+H: show/hide taskbar
- F12 or Esc: exit
