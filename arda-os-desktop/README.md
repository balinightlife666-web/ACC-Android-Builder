# ARDA OS Desktop v0.1

Safe-mode Windows cyberdeck launcher.

## Behavior
- Full-screen launcher layered over Windows.
- Does not replace Explorer.
- Alt+Tab still works.
- Minimize button reveals the normal Windows desktop.
- Esc/F12 can exit ARDA OS Desktop.
- Animated code-stream background.
- Live CPU/RAM/storage/network telemetry.
- Fast links: ACC OS X, WhatsApp, Note, Facebook, Instagram.
- Apps drawer scans Windows Start Menu shortcuts with search.
- Optional per-user startup toggle.

## Shortcuts
- ESC or F12: exit ARDA OS Desktop
- Ctrl+Space: open Apps drawer
- Alt+Tab: switch apps normally

## Safety
No administrator rights are requested. Windows shell and taskbar remain intact.
