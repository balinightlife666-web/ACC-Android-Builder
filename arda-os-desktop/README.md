# ARDA OS Desktop v0.3.1

Safe-mode Windows cyberdeck launcher.

## v0.3.1
- ROOT@ARDA / FASTLINK / WINDOWS SHELL / ALT+TAB is locked to the lower-right deck.
- Left side remains clean around ACC CORE and quick modules.
- If AUTOSTART was already enabled from an older build, launching v0.3.1 repairs the startup target to the current build automatically.
- Keeps Apps, telemetry, ACC CORE, Files/Chrome/Spotify/Discord, taskbar toggle, and visual app drawer.

## Shortcuts
- Ctrl+Space: Apps
- Ctrl+H: show/hide taskbar
- F12 or Esc: exit

## Safety
ARDA OS Desktop does not replace Explorer and does not require administrator rights.
